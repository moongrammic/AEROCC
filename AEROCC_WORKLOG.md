# AEROCC — журнал проделанной работы

Актуально на 16 ноября 2026 года. Целевая модель — **Gigabyte AERO X16 1VH**, проверенная версия BIOS — **FB0A**. Работа велась в текущей рабочей копии проекта .NET 8 с WPF-приложением, CLI и фоновой службой.

## Аудит проекта

- Codex Security проверил 53 текстовых файла исходной рабочей копии и зафиксировал **7 замечаний: 5 средней и 2 низкой серьёзности**. Они касаются прав на запись команд через IPC, проверки подлинности службы, ограничений запросов, прав на каталог установки и файл MOF, разбора Raw Input и записи обычных нажатий в диагностический журнал. Для рисков установки и MOF важны фактические права на каталоги машины.
- В управлении охлаждением обнаружены два основных сбоя. Ошибка чтения WMI превращалась в нулевое показание, по которому кривая могла снизить охлаждение. Запись профиля сообщала об успехе даже при отказе отдельных операций WMI.
- Ревью WPF/XAML показало, что «фиксированная скорость» в процентах выбирает одну из четырёх ступеней EC. Маркер редактора вычисляется по кривой, а RPM измеряются отдельно. В тепловом окне подпись «45 сек» обозначает 45 отсчётов с переменным интервалом, а градусы и ватты показаны на общей шкале.
- Полный переход на Rust отложен до стабилизации охлаждения, APU и IPC. Текущие исправления сделаны в C# и WPF.

Кривая пропускает изменение ступени при недоступной или устаревшей температуре. В редакторе в этом случае скрывается маркер, а на температурном графике CPU появляется разрыв. 2. **Запись профилей.** `SetFanProfile` учитывает результат каждой операции. При отказе во время записи Eco, Game или Turbo он прерывает выбранную последовательность и пытается записать настройки Normal. GUI обновляет выбранный профиль после успешной записи. При отказе он снимает выделение, показывает неизвестное состояние EC и останавливает динамическую кривую. ## Проверки и результаты

- **Сборка.** Собраны все проекты в конфигурациях Debug и Release без предупреждений и ошибок.
- **Имитатор WMI.** Прошли 33 сценария записи профилей. Проверено успешное выполнение, отказ на каждом шаге, порядок попытки возврата к Normal и отклонение неизвестного профиля.
- **Телеметрия на ноутбуке.** Чтения из PowerShell и CLI дали CPU **41–45 °C**, вентилятор 1 **0–2 127 об/мин**, вентилятор 2 **0–2 380 об/мин**.
- **Профили EC на питании от сети.** В прямом обратном чтении подтверждены флаги EC:
  - **Eco:** `AutoFan=0, FixedFan=0, StepFan=0, NvThermal=1`
  - **Normal:** `AutoFan=0, FixedFan=0, StepFan=0, NvThermal=0`
  - **Game:** `AutoFan=1, FixedFan=0, StepFan=0, NvThermal=0`
  - **Turbo:** `AutoFan=0, FixedFan=1, StepFan=1, FixedSpeed=100%`
- **Безопасность IPC и файловой системы.** Проверена блокировка мутирующих команд для непривилегированных клиентов и установка ACL только для SYSTEM и Administrators на файл MOF.
